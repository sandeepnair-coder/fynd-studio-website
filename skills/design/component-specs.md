# Component Specs — Fynd Studio

Quick specs for commonly used components.

---

## Buttons

| Property | Value |
|----------|-------|
| Border radius | 250px (pill) |
| Font | Inter, 14px, weight 500 |
| Padding | 12px 24px (default), 16px 32px (large) |
| Variants | primary, primary-light, secondary, secondary-light |

## Badges / Tags

| Property | Value |
|----------|-------|
| Border radius | 2000px |
| Font | Inter Display, 12px, weight 400 |
| Padding | 8px 12px |
| Colors | Use brand tint pairs (-fill bg + -text color) |

## Cards

| Property | Value |
|----------|-------|
| Border radius | 16px |
| Border | 1px solid --neutral--neutral-20 |
| Padding | 32px (desktop), 24px (tablet), 20px (mobile) |
| Hover | border-color: --neutral--neutral-30, shadow: 0 4px 24px rgba(0,0,0,0.06) |

## Section Headers

| Property | Value |
|----------|-------|
| Label | 12px, uppercase, letter-spacing 0.08em, muted color |
| H2 Title | 36-48px, bold |
| Subtitle | 16px, --text--subtext |
| Alignment | Centered (default) or left-aligned |
| Max width | 720px (centered headers) |
| Bottom margin | 56px before content |

## Icons (Lucide)

| Context | Size |
|---------|------|
| Inline / UI | 16px |
| Cards / features | 20px |
| Decorative / hero | 24px |
| Stroke width | Always 1.5 |
| Style | Outline only, never filled |
