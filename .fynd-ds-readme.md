# Fynd One Design System — Installed

**Framework:** Vanilla HTML  
**Tokens:** `assets/css/fynd-tokens.css`  
**CLAUDE.md:** `CLAUDE.md`  

## Next steps

### 1 — Add Fynd Sans font files
Place the following `.woff2` files in `assets/fonts/`:
```
assets/fonts/FyndSans-Regular.woff2
assets/fonts/FyndSans-Medium.woff2
assets/fonts/FyndSans-SemiBold.woff2
assets/fonts/FyndSans-Bold.woff2
```
Get them from the design assets repo or contact design@fynd.com.

### 2 — Install open-source fonts
```bash
npm install @fontsource/inter-display @fontsource/inter
```
Then uncomment the `@fontsource` import lines in your global stylesheet.

### 3 — Install Lucide icons
```bash
npm install lucide-react
```

### 4 — Import tokens in your global stylesheet
```css
@import './fynd-tokens.css'; /* always first */
```

Refer to `CLAUDE.md` for full component patterns, token reference, and dos/don'ts.
